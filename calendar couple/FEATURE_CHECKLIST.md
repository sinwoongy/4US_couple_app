# 기능 체크리스트

이 문서는 현재 `couple_calendar_web` 프로젝트에서 구현된 기능과, 다음 단계에서 보완하거나 추가하면 좋은 항목을 정리한 체크리스트입니다.

## 현재 구현된 기능

- [x] Next.js App Router 기반 프로젝트 구성
- [x] TypeScript 기반 컴포넌트 및 유틸 작성
- [x] 메인 대시보드 UI 구성
- [x] 히어로 영역에 앱 이름 `COUPLE CALENDAR` 반영
- [x] 커플 코드 입력 및 브라우저 저장
- [x] 같은 커플 코드 기준 데이터 조회 및 생성
- [x] 파트너 이름 2개 입력 및 저장
- [x] 기념일 입력 및 저장
- [x] D-Day 계산 및 표시
- [x] 월간 캘린더 렌더링
- [x] 날짜별 일정 표시
- [x] 전체 일정 목록 표시
- [x] 일정 추가
- [x] 일정 수정
- [x] 일정 삭제
- [x] 일정 색상 선택
- [x] 종일 일정 여부 선택
- [x] 시작 시간 / 종료 시간 입력
- [x] 날짜 클릭 시 달력 영역 내 `Quick Add` 미니 창 열기
- [x] 선택한 날짜 기준 `Quick Add` 폼 자동 연동
- [x] Day View 패널에서 선택 날짜 일정 확인
- [x] Supabase 브라우저 클라이언트 연결
- [x] Supabase Realtime 구독으로 변경 사항 반영
- [x] Supabase `events` 수정 정책 반영
- [x] Supabase 미설정 시 `localStorage` 대체 동작
- [x] 로딩 화면 구성
- [x] 에러 화면 구성
- [x] 기본 반응형 레이아웃 구성
